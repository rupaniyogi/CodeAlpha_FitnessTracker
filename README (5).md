# CodeAlpha_FitnessTracker

Task 3 – Fitness Tracker App (CodeAlpha App Development Internship)

A simple fitness tracking app built with HTML, CSS and JavaScript (no libraries).

## Features
- Manually log activity: date, exercise type, workout time, calories burned and steps
- **Dashboard** with today's progress bars for steps, calories and workout minutes
- Editable daily goals
- **Weekly bar chart** (last 7 days) switchable between steps, calories and minutes, with weekly total and daily average
- History list with delete option
- Data is saved in the browser using localStorage, so it stays after refresh
- Responsive layout with automatic light/dark mode

## Run
Open `index.html` in any browser. No installation needed.

## Host free on GitHub Pages
